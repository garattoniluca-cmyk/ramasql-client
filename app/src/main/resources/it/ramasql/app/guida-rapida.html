Guida rapida di RamaSQL Client

RamaSQL Client è un programma per imparare i database con MariaDB e MySQL. La regola d'oro: ogni operazione mostra l'SQL che esegue. Prima di toccare il database compare l'anteprima: leggila, poi premi Esegui. Tutto quello che il programma esegue finisce nel Registro in basso.

Non sai a cosa serve qualcosa? Fermati con il mouse sopra: compare una spiegazione. Da tastiera si apre con Ctrl+F1. Anche le voci degli elenchi a discesa (tipi, motori, azioni delle chiavi esterne…) hanno la loro.

1. Collegarsi

Nella schermata iniziale ogni riquadro è una connessione salvata: un clic, la password, ed entri. Con Nuova connessione scrivi indirizzo, porta (di solito 3306) e utente. La password non si salva mai. Se qualcosa non va, il programma dice il motivo in italiano (server spento, password sbagliata…).

2. Il navigatore

A sinistra ci sono i cataloghi (database) con le loro tabelle e viste. Clic destro su un nodo per le operazioni: creare, rinominare, svuotare, eliminare, vedere l'SQL di creazione. Le operazioni pericolose chiedono di riscrivere il nome per conferma. F5, con il fuoco nel navigatore, lo rilegge dal server.

3. Creare le tabelle

Nuova tabella apre l'editor: nella scheda Colonne scegli nome, tipo e opzioni; in Indici la chiave primaria e gli indici; in Chiavi esterne i collegamenti con le altre tabelle (cosa succede se la riga «padre» si elimina: RESTRICT, CASCADE, SET NULL). Sotto vedi sempre l'SQL che verrà eseguito. Applica lo esegue e poi rilegge la tabella dal server per mostrarti com'è davvero.

4. Inserire i dati

Clic destro su una tabella → Apri tabella: si apre la griglia. Scrivi nelle celle, aggiungi righe, incolla da Excel (Ctrl+V). Niente arriva al server finché non premi Conferma: vedi prima le istruzioni INSERT, UPDATE e DELETE. Le celle sbagliate si colorano e il suggerimento dice perché.

5. Scrivere SQL

Nuova query apre l'editor SQL. Ctrl+Invio esegue l'istruzione sotto il cursore, Ctrl+Maiusc+Invio tutto lo script, Esc interrompe, Ctrl+Spazio completa nomi di tabelle e colonne. Gli errori del server compaiono con una spiegazione e il punto evidenziato.

6. Query visiva e viste

Nuova query visiva: trascina le tabelle nel diagramma, collega le colonne per le unioni, spunta le colonne da mostrare. La scheda SQL accanto mostra la stessa query in testo, e le due restano allineate. Salva come vista… la conserva nel database come vista.

7. Importare, esportare, ripristinare

Importa: dati da un file CSV (anche di Excel) o JSON, con anteprima, tipi proposti e rapporto delle righe scartate. Esporta/Dump: una copia in un file .sql di tabelle o cataloghi interi. Importa → Esegui script SQL… rimette tutto a posto da un file .sql (anche fatto con mysqldump o Navicat).

8. Modello ER

Modello ER disegna le tabelle e le loro relazioni. Le linee piene sono le chiavi esterne vere; quelle tratteggiate sono relazioni che disegni tu o che il programma ti suggerisce dai nomi delle colonne: vivono solo nel file del modello e non toccano il database.

Tutto da tastiera

F6 (e Maiusc+F6) passa da un'area all'altra: barra degli strumenti, navigatore, scheda aperta, pannello SQL. Dentro un'area Tab va avanti e Maiusc+Tab indietro; da una tabella si esce con Ctrl+Tab. Nella barra le frecce scelgono il pulsante e Spazio lo preme. Nel navigatore le frecce scelgono e aprono i nodi, Maiusc+F10 (o il tasto del menu) apre il menu del nodo. Nelle tabelle F2 modifica la cella, Spazio accende o spegne una casella, Alt+Giù apre la lista della cella: le frecce mostrano accanto la spiegazione di ogni voce, Invio sceglie, Esc lascia com'era. F10 porta al menu in alto. Nelle schede con le linguette, le frecce cambiano linguetta.

Scorciatoie utili

Ctrl+F1 spiegazione dell'elemento con il focus · Ctrl+Invio esegui l'istruzione · Ctrl+Maiusc+Invio esegui tutto · Esc interrompi · Ctrl+F cerca · Ctrl+/ (la barra del tastierino numerico) commenta le righe · Ctrl+S salva lo script nell'editor SQL e, nella griglia, conferma le modifiche (dopo l'anteprima) · F5 nel navigatore lo rilegge · Ctrl+, impostazioni · Ctrl+rotella ingrandisci il carattere (nel modello ER: lo zoom del diagramma).
