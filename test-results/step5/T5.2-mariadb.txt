# T5.2 — andata e ritorno di TableDiff su MariaDB
# Classe: it.ramasql.it.step5.T52AndataRitornoTest (step5, it)
# Per caso: SQL applicato con SqlExecutor, esito, confronto riletto/atteso e diff residuo.
# Casi eseguiti: 39, superati: 39
# Atteso = modello chiesto + sole regole su ciò che decide il server (javadoc della classe):
#  R1 catalogo di prova; R2 colonne numerate 1..n; R3 engine/charset/collation/AUTO_INCREMENT
#  non specificati = scelti dal server; R4 charset/collation di colonna uguali alla tabella =
#  ereditati; R5 NULL senza default = DEFAULT NULL, NOT NULL con DEFAULT NULL = nessun default;
#  R6 default numerici per valore; R7 NOW()/current_timestamp() = CURRENT_TIMESTAMP;
#  R8 ordine di indici e FK del lettore. Nessun altro campo è escluso dal confronto (equals).
