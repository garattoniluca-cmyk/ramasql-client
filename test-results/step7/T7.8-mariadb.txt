T7.8 — due schede «Query visiva» su MariaDB
Cataloghi: A = ramasql_test_ui_visual78a_zdrpyz, B = ramasql_test_ui_visual78b_tovpoz
SQL della scheda A:
SELECT
	`libri`.`titolo`,
	`editori`.`id`,
	`editori`.`nome`,
	`editori`.`citta`
FROM
	`editori`
	INNER JOIN `libri`
	 ON `editori`.`id` = `libri`.`id_editore`
WHERE
	`libri`.`anno` < 1960
ORDER BY
	`libri`.`titolo` ASC
SQL della scheda B:
SELECT
	`studenti`.`cognome`,
	`studenti`.`classe`
FROM
	`studenti`
WHERE
	classe = '3A'
ORDER BY
	cognome ASC
