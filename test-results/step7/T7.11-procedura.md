# T7.11 — Prova d'uso della query visiva (da fare con una persona)

**Chi:** una persona che non ha mai visto RamaSQL Client (meglio uno studente). **Chi osserva:** il docente, in silenzio.
**Tempo massimo:** 5 minuti. **Criterio:** consegna completata in meno di 5 minuti **senza aiuto**.

## Preparazione (prima che arrivi la persona, ~3 minuti)

1. Doppio clic su `avvia.cmd`; connettiti al server dalla tessera.
2. Se non c'è ancora, crea un catalogo con la biblioteca: nel navigatore, tasto destro sul server → *Nuovo catalogo…*
   (es. `ramasql_test_prova_uso`), poi apri *Nuova query* ed esegui il contenuto di `it-tests/fixtures/biblioteca.sql`
   dopo `USE ramasql_test_prova_uso;`.
3. Seleziona il catalogo nel navigatore. Chiudi tutte le schede. Fai partire il cronometro quando la persona si siede.

## Consegna (da leggere alla persona, una volta sola)

> «Con questo programma, senza scrivere SQL, prepara l'elenco dei soci con il numero di prestiti di ciascuno,
> solo per chi ne ha più di 3.»

## Cosa osservare (senza intervenire)

## Controllo del risultato

L'SQL prodotto (vista **SQL** della scheda) eseguito anche in Navicat (test **T7.12**) deve dare le stesse righe di:

```sql
SELECT s.cognome, s.nome, COUNT(p.id) AS prestiti
FROM soci s INNER JOIN prestiti p ON p.id_socio = s.id
GROUP BY s.id, s.cognome, s.nome
HAVING COUNT(p.id) > 3;
```
