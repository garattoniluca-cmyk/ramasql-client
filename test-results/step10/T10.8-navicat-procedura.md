# T10.8 — metà Navicat: ripristinare con il client un dump prodotto da Navicat

La metà `mysqldump`/`mariadb-dump` di T10.8 è automatica (`T107T109DumpSulServerTest.t108_…`). Per la metà Navicat
serve Navicat: quando c'è un file, la si automatizza mettendolo in `it-tests/fixtures/navicat/` (vedi sotto).

## Con una persona (10 minuti)

1. In Navicat, sul server MariaDB (poi MySQL): catalogo con la biblioteca (per esempio `ramasql_test_navicat`, già
   usato per i test N degli step 3–6, oppure uno nuovo in cui si esegue `it-tests/fixtures/biblioteca.sql`).
2. Tasto destro sul catalogo → *Dump SQL File* → *Structure And Data…* → salva `biblioteca-navicat.sql`.
3. Nel client: crea un catalogo vuoto (`ramasql_test_navicat_ripristino`) dal navigatore (tasto destro sul server →
   *Nuovo catalogo…*).
4. Barra → *Importa* → *Esegui script SQL…* → *Scegli…* `biblioteca-navicat.sql`; *Catalogo*: quello appena creato;
   *Se un'istruzione sbaglia*: *Fermati*; *Esegui* → nell'anteprima controlla le prime istruzioni → *Esegui*.
5. **Atteso:** la barra avanza, «Fatto: … 0 con errore»; nel navigatore le 6 tabelle e le 2 viste; i dati aperti con
   doppio clic sono quelli della biblioteca (200 libri, 100 soci, 500 prestiti).
6. Se qualcosa non va: il rapporto indica riga del file, istruzione ed errore spiegato → segnalarlo (è un difetto del
   client finché non si dimostra il contrario).

## Per automatizzarla

Copiare il file in `it-tests/fixtures/navicat/biblioteca-navicat.sql`: il test T10.8 lo trova e lo ripristina come
quelli di `mysqldump` (il resoconto lo dice).
