## 1 RESTRICT: DELETE del padre → 1451
server: MySQL 8.0.40
struttura (generatore → SqlExecutor):

      `id` INT UNSIGNED NOT NULL,
      `nome` VARCHAR(50) NOT NULL,
      PRIMARY KEY (`id`)
    ) ENGINE=InnoDB;
    CREATE TABLE `libri` (
      `id` INT UNSIGNED NOT NULL,
      `titolo` VARCHAR(100) NOT NULL,
      `id_editore` INT UNSIGNED NULL,
      PRIMARY KEY (`id`)
    ) ENGINE=InnoDB;
