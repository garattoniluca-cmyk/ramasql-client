T2.3 — errori di connessione provocati contro MySQL (flusso: clic sulla tessera → password → tentativo → finestra d'errore)

1-host-inesistente  (87 ms)
  profilo: ramasql_test@host-che-non-esiste.invalid:3307
  causa: UNKNOWN_HOST
  messaggio: Il computer «host-che-non-esiste.invalid» non si trova in rete: il nome non corrisponde a nessun indirizzo. Correggi il campo Host (controlla come è scritto) oppure usa l'indirizzo IP.
  originale: Errore di rete: SQLSTATE 08000 · java.net.UnknownHostException: host-che-non-esiste.invalid
  schermata: T2.3-mysql-1-host-inesistente.png

2-porta-chiusa  (81 ms)
  profilo: ramasql_test@127.0.0.1:3399
  causa: PORT_CLOSED
  messaggio: Il computer «127.0.0.1» risponde, ma sulla porta 3399 nessun server accetta connessioni. Correggi il campo Porta (di solito 3306; controlla quella indicata da chi gestisce il server) e verifica che il server MariaDB o MySQL sia avviato.
  originale: Errore di rete: SQLSTATE 08000 · java.net.ConnectException: Connection refused: getsockopt
  schermata: T2.3-mysql-2-porta-chiusa.png

3-password-errata  (80 ms)
  profilo: ramasql_test@127.0.0.1:3307
  causa: ACCESS_DENIED
  messaggio: Il server ha rifiutato l'accesso all'utente «ramasql_test»: nome utente o password sbagliati. Riscrivi la password (attenzione a maiuscole e minuscole) e controlla il campo Utente.
  originale: Errore 1045 (SQLSTATE 28000): (conn=5629) Access denied for user 'ramasql_test'@'localhost' (using password: YES)
  schermata: T2.3-mysql-3-password-errata.png

4-catalogo-senza-permesso  (82 ms)
  profilo: ramasql_test@127.0.0.1:3307 catalogo mysql
  causa: CATALOG_ACCESS_DENIED
  messaggio: L'utente «ramasql_test» non ha il permesso di usare il catalogo «mysql». Correggi il campo Catalogo del profilo (puoi lasciarlo vuoto) oppure chiedi il permesso a chi amministra il server.
  originale: Errore 1044 (SQLSTATE 42000): (conn=5630) Access denied for user 'ramasql_test'@'localhost' to database 'mysql'
  schermata: T2.3-mysql-4-catalogo-senza-permesso.png

5-catalogo-inesistente  (79 ms)
  profilo: ramasql_test@127.0.0.1:3307 catalogo ramasql_test_non_esiste
  causa: UNKNOWN_CATALOG
  messaggio: Il catalogo «ramasql_test_non_esiste» non esiste su questo server. Correggi il nome nel campo Catalogo del profilo, oppure lascialo vuoto.
  originale: Errore 1049 (SQLSTATE 42000): (conn=5631) Unknown database 'ramasql_test_non_esiste'
  schermata: T2.3-mysql-5-catalogo-inesistente.png
