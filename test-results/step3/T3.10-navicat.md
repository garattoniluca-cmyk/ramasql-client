# T3.10 (N) — Controllo incrociato con Navicat dopo T3.6

Test **N**: lo esegue l'utente con Navicat, non l'agente. I test automatici di T3.6
(`app/src/test/java/it/ramasql/app/step3/T36OperationsTest`) creano e poi **distruggono** i loro cataloghi
`ramasql_test_s3_ops_*`: sul server non resta nulla da guardare. La prova va quindi preparata a mano dal
coordinatore (o dall'utente) con il client, poi guardata in Navicat.

## Preparazione (nel client, su MariaDB :3306 e poi su MySQL :3307)

1. Connettersi con l'utente `ramasql_test` (tessera del server).
2. Navigatore → tasto destro sul server → **Nuovo catalogo…** → nome `ramasql_test_navicat_t310`,
   charset **latin1**, collation **latin1_swedish_ci** → *Mostra SQL…* → nell'anteprima deve comparire
   ``CREATE DATABASE `ramasql_test_navicat_t310` CHARACTER SET latin1 COLLATE latin1_swedish_ci;`` → **Esegui**.
3. Caricare la `biblioteca` nel catalogo (da Navicat: *Execute SQL File…* di `it-tests/fixtures/biblioteca.sql`
   sul catalogo `ramasql_test_navicat_t310`), poi nel client tasto destro sul catalogo → **Aggiorna**.
4. Tasto destro su `autori` → **Rinomina…** → `scrittori` → **Esegui**.
5. Tasto destro su `prestiti` → **Svuota** → riscrivere `prestiti` → **Svuota**.
6. Tasto destro su `prestiti` → **Elimina** → riscrivere `prestiti` → **Elimina**.
7. Pannello SQL → Registro: quattro righe con origine «Navigatore», esito OK e durata.

## Cosa guardare in Navicat (per ciascun server)

| Dove | Atteso |
|---|---|
| Connessione → tasto destro su `ramasql_test_navicat_t310` → *Edit Database…* | **Character set: latin1**, **Collation: latin1_swedish_ci** (quelli scelti nel client) |
| Elenco tabelle del catalogo (F5 in Navicat) | c'è **`scrittori`**, **non** c'è `autori` (tabella rinominata) |
| Elenco tabelle del catalogo | **non** c'è `prestiti` (tabella eliminata) |
| *Design Table* su `libri_autori` → *Foreign Keys* | la chiave `fk_libri_autori_autori` ora riferisce **`scrittori`** (la rinomina ha seguito le FK) |
| Vista `v_prestiti_aperti` | risulta non valida (usa `prestiti`, eliminata): è l'effetto atteso dell'eliminazione, non un difetto del client |

Se Navicat mostra qualcosa di diverso da ciò che il client dichiara, è un difetto del client (regola 2 di
`CLAUDE.md`): annotarlo in `docs/BUGS.md`.

## Pulizia

Dal client: tasto destro su `ramasql_test_navicat_t310` → **Elimina catalogo** → riscrivere il nome →
**Elimina** (verifica anche la conferma rafforzata su `DROP DATABASE`).
