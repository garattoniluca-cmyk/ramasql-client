# T12.14 — Scegliere leggendo solo i suggerimenti (da fare con una persona)

**Chi:** uno studente che non ha mai visto RamaSQL Client. **Chi osserva:** il docente, in silenzio (non spiega
nulla: tutto quello che serve deve essere nei suggerimenti). **Tempo:** circa 10 minuti.
**Criterio:** per ciascuna delle due scelte lo studente **sa dire perché ha scelto**, con parole sue, usando ciò che ha
letto nei suggerimenti. Se non ci riesce, il testo del suggerimento si riscrive (chiave indicata sotto).

## Preparazione (prima che arrivi lo studente, ~3 minuti)

1. Doppio clic su `avvia.cmd` (o `RamaSQL.exe` della versione portabile); connettiti al server dalla tessera.
2. Crea un catalogo di prova con la biblioteca (nel navigatore, tasto destro sul server → *Nuovo catalogo…*, es.
   `ramasql_test_prova_t1214`; poi *Importa → Esegui script SQL…* con `it-tests/fixtures/biblioteca.sql` e il catalogo
   come destinazione).
3. Nel navigatore, tasto destro su **prestiti** → *Progetta tabella…*: si apre l'editor della tabella. Lascia la
   finestra così. (Il carattere si può ingrandire con Ctrl+rotella se si proietta.)

## Consegna 1 (da leggere allo studente, una volta sola)

> «Questa tabella deve registrare i prestiti della biblioteca e non deve mai perdere dati né avere prestiti di libri
> che non esistono. Nella linguetta **Opzioni** scegli il motore della tabella, **InnoDB** o **MyISAM**. Puoi leggere
> le spiegazioni passando con il mouse sulle voci della lista, o con le frecce della tastiera. Poi dimmi perché hai
> scelto così.»

## Consegna 2

> «Nella linguetta **Chiavi esterne**, sulla chiave verso **soci**, scegli che cosa succede ai prestiti se un socio
> viene eliminato: **CASCADE** o **RESTRICT** (colonna *ON DELETE*). Leggi le spiegazioni delle voci. Poi dimmi perché.»

Lo studente **non preme *Applica***: si guarda solo la scelta e la motivazione.

## Cosa osservare

| Punto | Osservato | Note |
|---|---|---|
| trova da solo la lista del motore (linguetta *Opzioni*) | | |
| apre la lista e legge la spiegazione **accanto** alle voci (mouse o frecce) | | |
| sceglie **InnoDB** | | |
| motivazione con parole sue (atteso: controlla le chiavi esterne / non perde i dati se si spegne il computer) | | |
| trova la colonna *ON DELETE* e apre la sua lista | | |
| legge le spiegazioni di **CASCADE** e **RESTRICT** | | |
| sceglie e motiva (atteso: RESTRICT se i prestiti sono lo storico da non perdere; CASCADE se «via il socio, via i suoi prestiti» — entrambe accettabili **se motivate**) | | |

## Esito

- Motore: scelto ______ — motivazione dello studente: ______________________ — ✅ / ❌
- ON DELETE: scelto ______ — motivazione dello studente: ______________________ — ✅ / ❌
- Frasi dette ad alta voce («cosa vuol dire…?», «non capisco…»):

Se una motivazione manca o è sbagliata, il suggerimento va riscritto: le chiavi sono in
`app/src/main/resources/it/ramasql/app/messages.properties` — `tableeditor.engine.InnoDB.tooltip`,
`tableeditor.engine.MyISAM.tooltip`, `tableeditor.fk.action.CASCADE.tooltip`, `tableeditor.fk.action.RESTRICT.tooltip`
(il controllo automatico della qualità dei testi è `T1211QualitaSuggerimentiTest`). Annotare l'esito e le riscritture in
`docs/JOURNAL.md` e ogni punto di attrito in `docs/BUGS.md`.

## Alla fine

Chiudi l'editor senza applicare (*Chiudi → Scarta*) ed elimina il catalogo di prova dal navigatore (tasto destro →
*Elimina catalogo*, riscrivendo il nome per conferma).
